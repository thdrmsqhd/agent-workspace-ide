# 11. IDE·확장 통합 명세

2026-09-23. 관련 ADR-001/004, TV-001/002. [화면](04-screen-specification.md), [프로세스](10-process-terminal-debug.md).

## 1. 호스트 선택과 경계

Theia는 첫 검증 후보이며 채택 완료가 아니다. 최종 선택 전 Core·UI 모형·계약 코드는 IDE SDK 없이 개발한다. 실제 IDE 패키지 연결은 packages/ide-integration만 담당한다.

IDE 연결 계약은 taskId → workspaceRoot, file URI, editor buffers, language context, debug context, terminal context다. 내부 task:// 같은 가상 경로를 모든 확장에 강제하지 않고 실제 file URI와 별도 taskId 매핑을 사용한다.

작업 전환은 활성 표시 문맥만 바꾸며 숨겨진 작업의 언어 서비스·확장 상태를 종료하지 않는다. 준비가 끝난 작업을 매번 다시 로드하는 구현은 요구 위반이다.

## 2. 기능별 검증 대상

아래는 제품명이 확정된 목록이 아니라 검증 후보를 찾는 기준이다. exact 버전·배포 가능성을 확인하기 전 특정 VSIX를 배포물에 넣지 않는다.

| 필수 기능 | 후보 선정 기준 | 실제 검증 |
| --- | --- | --- |
| Java 언어 기능 | Eclipse JDT LS 기반 호환 확장 등 | 교차 파일 선언 이동·자동완성·진단·이름 변경 |
| Java 디버깅 | 선택 언어 확장과 호환하는 디버그 어댑터 | 중단점·단계 실행·지역 변수·스택·재시작 |
| Python | 호환 Python 언어 확장·서버 | 모듈 자동완성·선언 이동·진단·가상환경 경로 선택 |
| 파일 아이콘 | 호환 file icon theme | Java/Python/폴더 아이콘·전역 적용 |
| Git/터미널/검색 | IDE 기본 모듈 우선 | 선택 워크트리 범위와 외부 변경 갱신 |

VS Code Marketplace를 독립 앱에서 그대로 사용할 수 있다고 가정하지 않는다. Open VSX 또는 배포 조건을 충족한 공식 VSIX를 사용한다. 설치 성공은 호환 성공이 아니다. 부족한 기능을 목록에서 삭제하는 대신 대체 후보를 검증한다.

## 3. 설정 범위

확장 설치·버전은 앱 전체 공통, 프로젝트별 끄기 UI는 없다. 활성화 이벤트에 따른 로딩은 정상이며 모든 확장을 무조건 상주시킨다는 뜻은 아니다.

프로젝트 설정은 각 워크트리의 설정 파일을 읽는다. 사용자 공통 설정과 workspace 설정의 우선순위는 선택 IDE의 일관된 동작을 유지한다. 앱 자체 설정과 OMP 설정을 확장 설정 파일에 섞어 쓰지 않는다.

설정이 잘못되면 파일 위치·문제를 표시하고 마지막 정상 설정으로 표시 기능만 유지한다. 실행 위험이 있는 launch 설정은 무시한 채 실행하지 않는다.

## 4. 파일·편집·탭

왼쪽 파일 트리는 활성 작업의 루트만 보여준다. 상단에 작업명·브랜치 또는 준비 중 읽기 전용 상태를 표시한다. 새 파일/이름 변경/삭제는 선택 루트 경계 확인 후 IDE 파일 서비스로 수행한다.

작업별 미저장 버퍼는 독립적으로 보존한다. 탭을 닫아도 dirty 버퍼를 폐기하지 않는다. 사용자가 '변경 버리기'를 명시하면 해당 파일의 미저장 내용만 버리고 디스크 내용을 읽는다. 에이전트 변경까지 되돌리지 않는다.

## 5. 업데이트·고장

첫 버전 확장 업데이트는 사용자가 요청하고 실행 작업이 없는 때 적용한다. 실행 중 호스트 재시작을 자동 유발하지 않는다. 설치 실패는 이전 버전을 유지하며 전체 앱 설정을 초기화하지 않는다.

확장 호스트 실패는 해당 기능 오류로 표시한다. 엔진은 가능한 범위에서 계속 실행하지만 필수 언어 서비스가 내려간 상태를 정상이라고 표시하지 않는다. 호스트 복구 시 dirty 버퍼·디버그 상태가 복구되는지 확인한다.

## 6. 잠금 파일과 호환 결과

docs/evidence/extensions에 ID·버전·출처·라이선스 확인 위치·IDE API 버전·기능 시험 결과를 기록한다. 패키지 잠금과 일치하는 조합만 릴리스한다. 아직 검증 결과가 없으므로 이 문서에는 설치 명령의 특정 버전을 발명하지 않는다.
