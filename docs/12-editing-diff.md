# 12. 파일 편집과 Diff 명세

2026-09-23. REQ-027, REQ-039, REQ-040. [저장](06-data-storage.md), [Git](09-git-worktrees.md).

## 1. 비교 자료

DiffInput={snapshotId,baseLabel,targetLabel,files:[{oldPath,newPath,changeKind,oldArtifact?,newArtifact?,binary,encoding,eol}]}.
각 텍스트는 실제 줄 배열을 유지한다. 표시용 모델에 spacer를 넣지 않는다. 줄 번호는 각 버전 자체 번호다.

기본 '작업 변경'은 작업 baseCommit 대 현재 파일, '반영 변경'은 최신 대상 대 통합 후보다. 비교 기준과 snapshot 시각을 화면에 명시한다. 코드가 변하면 '새 변경 있음'과 새 snapshot 생성 액션을 표시한다. 사용자가 읽는 diff를 중간에 임의 재배치하지 않는다.

## 2. 표시 규칙

| 경우 | 왼쪽 | 오른쪽 | 연결 |
| --- | --- | --- | --- |
| 삽입 | 실제 기존 코드만 | 추가 구간 초록 | 왼쪽 삽입 경계에서 오른쪽 블록 |
| 삭제 | 삭제 구간 빨강 | 실제 남은 코드만 | 왼쪽 블록에서 오른쪽 경계 |
| 교체 | 삭제 표시 | 추가 표시 | 대응 블록 |
| 파일 전체 추가/삭제 | 존재하지 않음 안내 | 존재하는 파일 코드 | 가짜 빈 코드 행 생성 금지 |
| 이름 변경 | 이전 경로 | 새 경로 | 내용 변경과 경로 변경 구분 |
| 바이너리 | 크기·해시·다운로드 | 크기·해시·다운로드 | 줄 비교 미지원 안내 |

실제 빈 줄은 그대로 보존한다. 초기 soft wrap은 끄고 수평 스크롤을 사용한다. 사용자가 wrap을 켜면 실제 줄의 시각적 확장만 허용하며 반대편 맞춤 공백은 만들지 않는다. 동일 구간 자동 접기는 기본 끔이다.

## 3. 탐색

기본 독립 스크롤. 변경 블록 선택/이전/다음 버튼은 두 뷰의 대응 블록 또는 경계를 같은 상단 여백 위치로 이동한다. 이후 한쪽 수동 스크롤이 다른 쪽을 강제로 움직이지 않는다.

연결 레이어는 viewport에 보이는 블록만 그린다. 화면 밖 상대 구간은 방향 표식으로 표시한다. 삭제/삽입 색 외 문자와 아이콘을 제공한다. diff 화면은 기본 읽기 전용이며 '파일 열기'로 편집기로 이동한다.

## 4. 사용자 편집과 외부 변경

파일 열 때 diskHash와 버퍼 revision을 기록한다. 외부 변경 감지 시 clean 버퍼는 커서 보존하며 갱신, dirty 버퍼는 사용자 초안 유지+충돌 알림이다.

선택지: 내 초안 유지하며 비교, 디스크 버전 사용, 수동 병합. '내 초안 저장'도 최신 diskHash를 조건으로 쓰며 다시 바뀌면 재충돌한다. 마지막 저장 승리 방식으로 조용히 덮지 않는다.

파일 삭제·이름 변경 중 dirty 버퍼가 있으면 유실시키지 않고 복구 버퍼로 유지한다. 원래 경로 복원 저장은 사용자 명시 조작으로 수행한다. 인코딩을 해석할 수 없으면 바이너리 취급하고 강제 UTF-8 저장하지 않는다.

## 5. 크기와 오류

설계 기본값: 파일당 5MiB 또는 100,000줄 초과 시 자동 정밀 diff 대신 크기 안내·원문 열기·사용자 요청 계산을 제공한다. 이 임계값은 데이터 삭제 조건이 아니다. 계산은 worker로 수행하고 취소 가능하게 한다.

첨부·스냅샷 읽기 실패는 어느 쪽이 실패했는지 표시한다. 빈 파일과 읽기 오류를 구별한다. 검토 승인에 필요한 snapshot을 못 읽으면 승인 버튼을 비활성화한다.

## 6. 검증

삽입·삭제·교체·빈 파일·CRLF/LF·한글·탭·긴 줄·바이너리·이름 변경·미저장 충돌을 포함한다. DOM의 표시 줄 수/실제 모델 줄 수와 화면 캡처를 함께 확인하여 가짜 정렬 행 0을 검증한다. 단계별 롤백은 구현하지 않는다.

## 7. 구현 상태

`packages/diff`는 실제 텍스트 줄과 EOL을 그대로 유지하고 삭제·삽입·교체 블록의 양쪽 경계를 계산한다. 중간 구간 비교 비용이 크면 `coarse`, 크기 임계 초과 시 `too_large`를 명시한다. `packages/files`는 작업 내부 UTF-8 파일의 디스크 해시를 조건으로 저장하고 외부 변경 시 E_FILE_CONFLICT를 반환한다. 편집기 두 뷰·viewport 연결선·dirty 버퍼/삭제·rename 복구 UI는 IDE 호스트 연결 전 미구현이다. 파일 해시 검사와 rename 사이의 외부 변경을 OS 수준에서 원자적으로 차단한다는 뜻이 아니다.
