# Agent Workspace IDE 문서 색인과 구현 진입점

문서 세트 v0.2 / 2026-09-23. 현재 단계는 **문서 작성 완료, IMP-01 기초 개발 환경 구성 중**이다. 공통 계약 빌드와 문서 검사는 가능하나 앱 실행·실연동 검증 전이다.

## 1. 목적과 사용 순서

코딩 에이전트가 기능·화면·예외·계약·검증·작업 순서를 한 세트로 확인하도록 작성했다. 사용자 합의에 따라 04 화면과 상황별 시나리오를 먼저 정하고, 05~14 → 15~16 → 17~18 순서로 구체화했다.

처음 읽을 때: 원명세 → 03 요구사항 → 04/04a 화면·시나리오 → 02 구조 → 담당 도메인 문서 → 16 수용 검증 → 17 작업 계획 → 18 실행 계약. 실제 코딩 착수는 17의 IMP-01~03부터다.

## 3. 최신 화면 결정

상단 새 요청 입력, 왼쪽 파일 트리, 가운데 전체 현황/작업별 탭, 오른쪽 프로젝트·에이전트 세션. 탭 닫기는 엔진 중단이 아니며 재열기 시 상태를 복원한다. 전체 현황에서는 파일 트리를 기본 접되 펼칠 수 있다. 이 결정은 초기 그림·이전 제안보다 우선한다.

## 4. 결정과 기본값의 구별

사용자 확정: 독립 Windows 앱, 12개 실제 동시 코딩, OMP 우선, 확장·IDE 기능, 비선택 IDE 유지, 카드·하위 트리, 워크트리, diff 빈 행 금지, 화면 배치·탭 의미.

설계 기본값: 패널 폭, 한 열 카드, 초안 저장 간격, 재시도 간격, 포트 풀, 로그 회전, 앱 소유 서버의 종료 정책, 내부 ID·API 명칭. 사용자가 세부 구현을 위임하여 이 문서 세트에서 정했다. 기능 범위를 줄이지 않는 범위에서 ADR로 조정할 수 있다.

기술 검증 필요: 최종 IDE/OMP/확장 버전, Windows 실제 중단·세션 이전, 다중 IDE 호스트 구성, RAM 목표. 문서 작성을 완료했다고 이 검증이 끝난 것은 아니다. 실패했을 때의 차단 범위와 대안은 01/08/17을 따른다.

## 5. 이번 변경 기록

- 기존 01~03과 원명세를 최신 화면 결정에 맞춰 연결했다.
- 04~18, 04a와 루트 AGENTS.md를 작성했다.
- 처음 48개 REQ에 탭·화면 배치 2개를 추가했다.
- 64개 상황·조작, 33개 명령, 23개 수용 시험, 18개 구현 작업을 연결했다.
- 후보 버전을 임의로 확정하거나 실행하지 않은 시험을 통과로 표시하지 않았다.
- IMP-01의 npm workspaces, 계약 패키지, 문서 검사와 기초 CI를 추가했다. 앱·연동 검증은 아직 진행되지 않았다.
